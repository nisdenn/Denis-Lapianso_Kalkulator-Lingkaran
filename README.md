# Kalkulator Lingkaran CLI

Sebuah program CLI interaktif berbasis Python untuk menghitung luas dan keliling lingkaran berdasarkan jari-jari yang diinputkan oleh pengguna.

## Fitur Utama

- Menghitung luas lingkaran
- Menghitung keliling lingkaran
- Menerima input desimal dengan koma atau titik
- Validasi input (mencegah input negatif atau non-angka)
- Loop interaktif untuk perhitungan berulang

## Cara Penggunaan

Pastikan Anda sudah menginstal Python (minimal versi 3.6).

```bash
python src/main.py
```

Anda akan diminta untuk memasukkan jari-jari lingkaran. Setelah perhitungan selesai, program akan menanyakan apakah Anda ingin menghitung ulang atau keluar.

## Struktur Direktori

- `src/` : Berisi kode sumber utama program.
